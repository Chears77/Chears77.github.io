成长日记 · AI 生成指南

你只管写，AI 帮你排成网页 — 三步搞定一篇成长日记

怎么用（给家长 / 用户）

  1. 把下面三样一起发给任意 AI（微信 / 豆包 / 通义 / 任意对话框）：
    ① 日记模板 diary-template.html　② 本说明（或直接发 AI生成说明.txt）　③ 你的文章（文字 + 图片）
  2. AI 会返回一个文件夹，例如 20260606-作文-我的探险之旅/，里面含 index.html + images/
  3. 把该文件夹整个丢进 mumu/4diaries/，双击 mumu/更新全部.bat（或 4diaries/更新日记.bat），列表与首页自动更新
提示：AI 生成的文件夹命名必须严格为「时间-主题-标题」，否则生成器无法正确归类和显示。

主题与配色（固定四色，不要自创）

文件夹中间的主题词，以及 HTML 里的 diary-theme，都只能从下面四个（或六个）里选：

主题机器码 diary-cat列表配色
作文essay粉
日记diary鹅黄
校园school蓝
父母期许parents紫
视频记录video深色
图片记录photo暖黄

index.html 必须有的机器信息

放在 <head> 里，生成器靠它归类与显示：

<meta name="diary-cat"    content="essay">
<meta name="diary-date"   content="2026-06-06">
<meta name="diary-theme"  content="作文">
<meta name="diary-cover"  content="images/cover.jpg">  <!-- 可选 -->
<meta name="diary-excerpt" content="一句话简介">        <!-- 可选 -->

版式要求（照模板即可）：顶部标题+日期、无大封面图、首字不放大、正文首行缩进、图片点开可放大（模板已含灯箱，保留那段 <script>）。

图片规则

  • 所有图片放进 images/ 子文件夹
  • 文件名用字母 / 数字（img01.jpg），避免中文和空格
  • HTML 引用用相对路径：images/img01.jpg
  • 每张图用：<figure><img src="images/img01.jpg" alt="说明" data-cap="说明"><figcaption>说明</figcaption></figure>

把下面这段发给 AI（复制即可）

【任务】根据我提供的文章（文字 + 图片），生成一个符合「任以沐成长纪念册」规范的网页文件夹。

【输出要求】
1. 生成一个文件夹，命名格式：时间-主题-标题
   · 时间 = 文章日期 8 位数字，如 20260606
   · 主题 = 固定四选一：作文 / 日记 / 校园 / 父母期许（纯视频或纯图片集用 视频记录 / 图片记录）
   · 标题 = 文章标题（去掉"作文："这类前缀）
   · 例：20260606-作文-我的探险之旅 、20260406-日记-夬石峡谷穿越 、20220401-校园-春日定格风筝节活动
2. 文件夹内含：
   · index.html（基于我给你的模板 diary-template.html，替换示例内容为你生成的真实内容，保留灯箱 script）
   · images/ 子文件夹（存放所有图片）
3. index.html 必须包含机器可读 meta（放在 head）：
   · diary-cat：essay / diary / school / parents / video / photo
   · diary-date：YYYY-MM-DD
   · diary-theme：作文 / 日记 / 校园 / 父母期许 / 视频记录 / 图片记录（须与文件夹中间主题一致）
   · diary-cover（可选）、diary-excerpt（可选一句话简介）
4. 图片处理：放入 images/，文件名用字母数字（img01.jpg），HTML 用相对路径 images/img01.jpg，每张用 figure 包裹并带 figcaption。
5. 版式：顶部标题+日期、无大封面图、首字不放大、正文首行缩进、图片点开可放大。

【交付】把生成的整个文件夹（含 index.html + images/）交还给我。
