# 法规录入通用模板（给 AI 用的「照着生成」范本）

> **用途**：你（用户）在网上看到新法规，把**本文件 + 法规链接/PDF/截图**一起发给任意 AI（豆包、通义、ChatGPT 等都行），
> 让 AI 按下面的格式生成一份 `.md` 文档，存到 `法规库/0新录入/` 文件夹即可。
> 后面的「一键更新」脚本会自动把文件按效力层级归位、校验、重建检索数据。
>
> ⚠️ 本模板适用于全部 12 类法规。**标准规范（GB/JGJ 等）** 另有更细的格式约定，见同级 `标准格式模板.md`。

---

## 一、让 AI 生成 md 的「复制即用」提示词

把下面整段复制，把《XXX》换成具体法规名，连同法规链接一起发给 AI：

```
请为《XXX》生成一份符合「工程建设法规AI知识库」规范的 Markdown 文档（只输出文档内容本身，不要加解释）。

要求：
1. 文档最前面必须用 YAML Front Matter（以 --- 包裹），必须包含以下字段并填全：
   - title：法规全称（与官方公布名称一致）
   - level：效力层级，只能取以下 12 类之一（务必选准）：
       法律 / 司法解释 / 中央行政法规 / 中央部门规章 / 中央规范性文件 /
       地方行政法规 / 地方规章 / 地方规范性文件 / 标准规范 /
       司法案例 / 行政案例 / 政策解读
   - doc_type：法律/法规/规章/标准/司法解释 填 law；判例/解读 填 doc
   - publisher：发布机构（如 全国人民代表大会常务委员会 / 国务院 / 住房和城乡建设部 / 四川省人大常委会）
   - doc_number：发文字号（如「主席令第86号」「法释〔2020〕25号」「GB/T 50319-2013」）；无则写 ""（空字符串）
   - publish_date / effective_date / revise_date：日期 YYYY-MM-DD；无则写 ""（空）
   - field：专业领域（如 招投标 / 施工 / 质量 / 安全 / 造价 / 通用），可写 ""
   - region：仅「地方类」(地方行政法规/地方规章/地方规范性文件) 必填，写 省 或 省/市（如 四川省 或 四川省/成都市）；中央类及其他写 ""
   - status：现行 / 已废止 / 待核实（绝大多数新法规填 现行）
   - verify_status：固定写 初稿待校核
   - source_url：官方来源链接，可写 ""
   - tags：关键词标签，可写 ""
2. 正文结构：
   - 法律/法规/规章/标准/司法解释：用「## 第X章 章名」+「### 第X条 条文」
   - 司法案例/行政案例/政策解读：用「## 分章」+「### 小节」
3. 文件名请命名为 `日期-发文字号-标题.md`（日期取 修订>施行>颁布 中最早有值者，YYYYMMDD；无文号则省略中段；标题过长可截断）。
   所在文件夹可任意，入库脚本会按 level 自动归位到正确的 NN-层级 文件夹，你无需关心文件夹。
4. 发文字号里的「/」改写为「-」（如 GB/T50319-2013）。
5. 已废止的法规必须加字段：superseded_by: 《替代它的法规名》（注明替代关系）。
```

## 二、生成的 md 长这样（示例，你不用手填，看个样子即可）

```markdown
---
title: 必须招标的工程项目规定
level: 中央部门规章
doc_type: law
publisher: 国家发展和改革委员会
doc_number: 国家发展改革委令第16号
publish_date: 2018-03-27
effective_date: 2018-06-01
revise_date: 
field: 招投标
region: 
status: 现行
verify_status: 初稿待校核
source_url: https://www.ndrc.gov.cn/
tags: 必须招标,规模标准
---

## 第一章 总则

### 第一条
为了确定必须招标的工程项目，规范招标投标活动，提高工作效率、降低企业成本、预防腐败，根据《中华人民共和国招标投标法》第三条的规定，制定本规定。

### 第二条
全部或者部分使用国有资金投资或者国家融资的项目包括：……
```

## 三、12 类 `level` 速查（让 AI 选对层级）

| level 取值 | 适用 | 例子 |
|------|------|------|
| 法律 | 全国人大及其常委会制定 | 建筑法、招标投标法 |
| 司法解释 | 最高法司法解释、全国人大常委会立法解释 | 法释〔2020〕25号 |
| 中央行政法规 | 国务院条例、规定 | 保障农民工工资支付条例 |
| 中央部门规章 | 国务院部委令 | 住建部令、国家发改委令 |
| 中央规范性文件 | 部委通知、意见、办法（全国适用） | 建市〔201X〕XX号 |
| 地方行政法规 | 省级人大/政府地方性法规、条例 | 四川省××条例 |
| 地方规章 | 省级政府规章 | 四川省××办法 |
| 地方规范性文件 | 省市规范性文件 | 成都市××通知 |
| 标准规范 | GB / JGJ 等强制性及推荐性标准 | GB/T 50319-2013 |
| 司法案例 | 最高法指导性/参考性案例 | 指导案例XX号 |
| 行政案例 | 行政部门通报的违法违规典型案例 | 住建部通报案例 |
| 政策解读 | 部委对重要规章、标准的官方解读 | ××政策解读 |

> 地方类（地方行政法规/地方规章/地方规范性文件）必填 `region`，且**文件平铺**在该层级文件夹下、**不要建省/市子文件夹**。

---

## 四、发文字号缩写规则（让 AI 简化，避免文件名过长）

- `中华人民共和国主席令`→`主席令`；`中华人民共和国国务院令`→`国务院令`
- 含「第X号」的中文数字一律转阿拉伯：`主席令〔2017〕第八十六号`→`主席令第86号`
- 长机构名缩写：`人民代表大会常务委员会`→`人大常委会`；`国家发展和改革委员会`→`国家发改委`
- 去掉冗余注释：`（解读）`、`（2019修订）`、`·工程建设领域专章` 等
- 总原则：缩写后文号尽量 ≤ 15 字

---

## 五、你（用户）要做的三件事

1. 把**本文件 + 法规链接**发给 AI，拿到生成的 `.md`。
2. 把 `.md` 存到 `法规库/0新录入/` 文件夹（没有就建一个，或让 AI 直接存进去）。
3. 双击 `法规库/rebuild.bat` 一键上线 → 本地刷新 `index.html` 即可看到。

> 详细步骤与排错见同级 `录入指南.md`。GitHub 网页同步由你手动复制 `3第二版` 到部署目录并 push（本知识库不自动化这块）。
