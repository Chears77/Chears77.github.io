# 文章模板使用说明

> 位置：`文章\笔记模板\使用说明.md`
> 日常你只需要记住一句话：**建文件夹 → 放 html 和图片 → 双击 bat**。

---

## 一、日常新增文章（三步）

1. **建文件夹**：在 `文章\` 下新建文件夹，命名 = `8位日期 + 文章标题`，例如 `20260908我的新文章`
2. **放内容**：文件夹里放 `index.html`（按模板生成，见下）和 `images\`（图片都放这里）
3. **双击 `文章\一键更新文章列表.bat`**

bat 会自动完成：
- 校验每篇文章的标题和日期，**以文件夹名为准回写**（改 `<title>`、页内大标题、日期角标）
- 重新生成目录页（articles.html）的文章列表
- 重新生成 articles.data.js → **所有文章页的左侧"全部文章"导轨同步更新**（无需改动任何文章 html）

> 注意：文件夹名不以 8 位日期开头的会被自动跳过；需要电脑已安装 Node.js。

---

## 二、把其他格式的文章交给 AI 处理

给 AI 的提示词（直接复制）：

> 请读取 `D:\github\homepage\Chears77.github.io\文章\笔记模板\使用说明.md`，按其中的模板规范，把我下面的文章转换成文章页，保存到 `文章\8位日期+标题\index.html`。

AI 必须遵守的规范：

**1. 输出位置**
- 新建文件夹 `文章\8位日期+标题\`
- 里面放 `index.html` 和 `images\`（图片本地化到 images，正文用相对路径 `images\xxx.jpg` 引用）

**2. 页面骨架**
- 以 `笔记模板\index.html` 为基底整页复制，顶栏、三主题切换、左右悬浮导轨、底部脚本引用**原样保留，不得删改**
- 只替换"填这里"注释附近的标题/日期和 `<div class="article-body">` 内的正文

**3. 三处必填**（写错了也没关系，双击 bat 会按文件夹名强制纠正）
- `<title>文章标题 - 安即是佛</title>`
- `<h1 class="article-title">文章标题</h1>`
- `<span class="article-date">2026年9月8日</span>`（中文日期）

**4. 正文写法（在 `<div class="article-body">` 内）**

| 内容 | 写法 |
|---|---|
| 普通段落 | `<p>……</p>`（自动首行缩进、两端对齐） |
| 小节标题 | `<h2>…</h2>` / `<h3>` / `<h4>`（右侧大纲自动生成、自动折叠） |
| 重点强调 | `<strong>…</strong>`（自动变主题色） |
| 格式/命令示例 | `<span class="fmt">1#吃饭20</span>`（浅底等宽高亮） |
| 金句/引用 | `<blockquote>…</blockquote>` |
| 单张图片 | `<figure><img src="images/1.jpg" data-cap="图注文字"><figcaption>图注文字</figcaption></figure>` |
| 多图并排 | `<div class="card-gallery">…多个 figure…</div>` |
| 外部链接 | 直接 `<a href="…">`，会自动新窗口打开 |

**5. 禁止事项**
- 不要删除页面尾部 `<script src="../articles.data.js"></script>` 和导轨脚本
- 不要引入外部 CDN 样式；所有样式都在页面内
- 不要使用粉色系（站点风格：蓝白 / 书卷 / 暗黑三主题）

---

## 三、文件清单（文章\ 目录）

| 文件 | 作用 | 是否要动 |
|---|---|---|
| `一键更新文章列表.bat` | 双击更新入口 | 只用不改 |
| `generate-index.js` | 校验回写 + 生成列表数据 | 只用不改 |
| `articles.data.js` | 所有文章页左侧导轨的数据源（自动生成） | 不要手改 |
| `articles.html` | 文章目录页（列表数据自动注入） | 样式可改，`var __D` 行勿动 |
| `笔记模板\index.html` | 模板壳源文件 | 改版才动 |
| `笔记模板\使用说明.md` | 本文件 | — |

> 有变更想上线时再提交推送，平时所有更新都只在本地生效。
